# 📚 InnovateX EduLib - Smart Digital Library System

A professional, university-grade Library Management System built with the MERN stack.

**Live Demo:** [https://innovatex-edulib-smart-library.vercel.app](https://innovatex-edulib-smart-library.vercel.app)

## 📂 Project Structure

- **/frontend**: React.js application (Vite, Lucide React, Recharts).
- **/backend**: Node.js & Express API (MongoDB, JWT, bcrypt).

## 🚀 Getting Started

### 1. Prerequisites
- Node.js installed
- MongoDB (Local or Atlas)

### 2. Setup Backend
```bash
cd backend
npm install
# Create a .env file with:
# PORT=5000
# MONGO_URI=your_mongodb_connection_string
# JWT_SECRET=your_secret_key
npm run dev
```

### 3. Setup Frontend
```bash
cd frontend
npm install
npm run dev
```
